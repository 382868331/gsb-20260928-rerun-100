# 应用扩展加载系统

本项目实现第一版本地子进程扩展：扩展进程是当前可执行文件的内置模式，不会下载、加载或执行外部代码。

## 内置扩展

- `echo` v1.2.0：提供 `echo`、可取消的 `sleep` 和故障测试方法 `crash`。
- `calculator` v2.0.1：提供 `add`、`verify`，启动前要求 `echo >= 1.0.0` 且具备 `echo` 能力。

宿主与子进程使用带换行分隔的 JSON 消息。启动时先协商协议版本、扩展名、版本和能力；每个进程代际收到随机会话 ID。响应必须携带该 ID，崩溃重启会生成新代际和新会话，不能继续冒充旧会话。

## 生命周期与故障隔离

- 启动前先检查依赖是否存在、版本是否兼容、能力是否完整以及是否存在循环。
- 依赖按拓扑序启动；关闭时宿主先停止接单，等待进行中的请求，再按反向顺序收尾。
- 请求超时只让当前请求失败，宿主发送取消消息并继续服务后续请求。
- 扩展异常退出只影响该扩展上尚未完成的请求；宿主回收旧进程并启动新代际。
- 每次任务都写入 JSONL 审计记录，包含扩展名、版本、代际、会话、方法、状态、耗时和错误。

## 运行与验证

```bash
go test ./... -count=1
go test -race ./... -count=1
go run ./cmd/extension-loader --audit extension-events.jsonl
```

演示会运行正常任务、超时任务、扩展崩溃和崩溃后的恢复请求，并在最后停止两个扩展。
